Игра «Прыжки: Выжить на платформе» не регистрирует пользователей, не собирает персональные данные и ничего о вас не отправляет разработчику. Единственное, что обращается к сети, — встроенная реклама. Ниже подробно о том, что при этом происходит.

  1. Что делает приложение

    Это аркадная игра, которая целиком работает на устройстве: код, графика и игровой движок упакованы внутрь приложения. Игра запускается и полностью играется без интернета — например в авиарежиме. Соединение нужно только для загрузки рекламных объявлений.

    Чего приложение не делает

    • не требует регистрации, входа и не создаёт аккаунт;
    • не запрашивает доступ к камере, микрофону, геолокации, контактам, звонкам, SMS и файлам;
    • не содержит встроенных покупок и не принимает платежи;
    • не передаёт разработчику ваши игровые данные и ничем вас не идентифицирует;
    • не показывает рекламу, которая мешает играть: баннеров поверх игрового поля нет.

  2. Данные, которые хранятся на вашем устройстве

    Игровой прогресс — лучший результат, накопленные монеты, открытые персонажи и настройки звука — сохраняется в локальном хранилище приложения на самом устройстве. Эти данные никуда не отправляются, доступны только самому приложению и удаляются вместе с ним при удалении игры или при очистке её данных в настройках Android.

  3. Реклама

    Для показа рекламы используется Yandex Mobile Ads SDK — компонент Рекламной сети Яндекса. Реклама показывается только по вашему выбору (просмотр видеоролика за игровой бонус) и между забегами. Рекламные объявления и связанные с ними данные обрабатывает Яндекс как оператор рекламной сети, а не разработчик игры.

  4. Реклама для детской аудитории

    Игра рассчитана в том числе на детей, поэтому рекламный SDK переведён в режим для детской аудитории. В этом режиме объявления неперсонализированные: они не подбираются на основе интересов, истории просмотров или профиля пользователя и дополнительно фильтруются по возрасту. Этот режим включён всегда и не зависит от настроек устройства.

  5. Разрешения приложения

    • INTERNET — загрузка рекламных объявлений. Без этого разрешения игра работает, но реклама не показывается;
    • ACCESS_NETWORK_STATE — проверка наличия соединения, чтобы не пытаться загрузить рекламу без сети и не расходовать заряд батареи.

    Других разрешений приложение не запрашивает.

  6. Ваши возможности

    • Сбросить или ограничить рекламный идентификатор — в настройках Android: «Google» → «Реклама» (на устройствах без сервисов Google — в разделе настроек конфиденциальности производителя);
    • Удалить все данные игры — удалить приложение или стереть его данные в настройках Android. Локальный прогресс будет удалён безвозвратно, резервной копии на сервере не существует;
    • Играть без рекламы — отключить интернет: игра полностью функциональна офлайн.

  7. Изменения политики

    Если состав обрабатываемых данных изменится — например появится новый рекламный формат или аналитика, — эта страница будет обновлена, а дата редакции в начале документа изменится. Существенные изменения будут отражены в описании обновления приложения в магазине.
